API Reference

AITrainingAPI

The primary facade for AI training interactions. Provides explicit GET/SET operations scoped exclusively to the training environment.

from src.api import AITrainingAPI

api = AITrainingAPI(sim_context=app)

Scope Isolation

All SET operations modify a training-local configuration copy. The main simulation state is never affected.

Constructor

ParameterTypeDescription
sim_contextLocalizationAppReference to the main application for read-only access to simulation state

GET Operations (Read Data)

MethodReturnsDescription
get_num_anchors()intNumber of anchors in the training environment
get_nlos_solutions_count()intCount of anchors currently in NLOS condition
get_algorithm_info()dictAlgorithm type, measurement noise, latest measurements, error, filter params
get_energy_info()dictEnergy level, consumption breakdown, battery life estimates
get_measurements()list[float]Latest distance measurements from all anchors
get_error()floatLatest localization error (Euclidean distance in meters)
get_los_conditions()list[bool]LOS/NLOS per anchor (True = LOS, False = NLOS)
get_registered_filters()list[str]All available localization filter names
get_available_algorithms()list[str]Sorted list of all algorithm display names
get_training_config()dictComplete training-local configuration snapshot
get_measurement_source()strCurrent source: "uwb", "imu", or "both"
get_imu_data(tag)dictLatest IMU readings (acceleration, angular_velocity, enabled flag)
get_gdop(tag, anchors)floatGeometric Dilution of Precision (lower = better geometry)
get_per_step_energy(dt)dictInstantaneous + cumulative energy data for one step
get_full_state()dictComplete API state snapshot (config + data + energy + filters)

info = api.get_algorithm_info()

SET Operations (Modify Training Configuration)

MethodParametersDescription
set_num_anchors(n)n: int (≥ 1)Set anchor count for training. Also updates energy adapter.
set_num_stacks(n)n: int (≥ 1)Set ranging stack count (more = better accuracy, higher energy)
set_input_mode(mode)mode: str"imu", "uwb", or "both"
set_measurement_source(source)source: strAlias for set_input_mode()
set_filter(name, **params)name: str, kwargsSelect localization filter and pass configuration parameters
set_energy_profile(**kwargs)kwargsConfigure: ranging_mode, uwb_frequency_hz, imu_enabled, battery_capacity_mAh, voltage

Example — Configure Training

api.set_num_anchors(6)
api.set_input_mode("both")         # Fused IMU + UWB
api.set_filter("NLOS-Aware AEKF", alpha=0.3, beta=2.0)
api.set_energy_profile(
    ranging_mode="DS-TWR",
    battery_capacity_mAh=500,
    voltage=3.3
)

Observation Builder

The build_step_observation() method constructs the canonical state dictionary sent to RL agents. It takes 16 parameters and returns a comprehensive observation.

obs = api.build_step_observation(
    agent_id=0, step=10, dt=0.005,
    true_pos=[1.0, 2.0], est_pos=[1.1, 1.9],
    tag=tag_obj, anchors=anchor_list,
    measurements={0: 3.2, 1: 5.6, 2: 2.9},
    los_conditions=[True, False, True, True],
    curr_error=0.15, prev_error=0.22,
    algorithm_name="EKF",
    movement_speed=1.5, movement_pattern="circular",
    channel_model=channel_conditions,
    measurement_source="uwb",
    active_anchor_count=3
)

TrainingDataAPI

API for offline data collection — buffer simulation data and export for supervised/offline learning.

from src.api import TrainingDataAPI

api = TrainingDataAPI(buffer_size=10000)

Constructor

ParameterTypeDefaultDescription
buffer_sizeint10000Maximum number of samples to keep in memory

Configuration Methods

MethodParametersReturnsDescription
configure(buffer_size, **kwargs)buffer_size: intselfReconfigure API settings. Supports method chaining.
select_data(em, channel, snr, filter_outputs, ground_truth, imu)All bool, default TrueselfSelect which data categories to collect

Collection Control

MethodReturnsDescription
enable_collection()selfStart collecting data into the buffer
disable_collection()selfStop collecting (data is retained)
reset()selfClear all collected data and reset state
is_collectingboolProperty: whether collection is currently active

Data Access

MethodReturnsDescription
get_latest_sample()DataSample | NoneMost recent collected sample
get_buffer()list[DataSample]All samples currently in the buffer
get_sample_count()intNumber of collected samples
get_synchronized_data(start_time, end_time)list[dict]Flat dictionaries (for pandas: pd.DataFrame(data))
get_statistics()dictCollection stats: error mean/std, SNR, LOS percentage

Export Methods

MethodParametersDescription
export_to_file(path, format)path: str, format: "npz"|"csv"|"json"Export collected data to file
export_for_pytorch(path)path: str (directory)Export as separate .npy files for features, anchors, targets

Streaming (Real-Time Callbacks)

MethodParametersDescription
stream_to_callback(callback)callback: Callable[[DataSample], None]Register a callback for each new sample (useful for online learning)
stop_streaming(callback=None)callback or NoneStop specific callback, or all if None

Complete Usage Example

from src.api import TrainingDataAPI

# 1. Configure
api = TrainingDataAPI(buffer_size=50000)
api.select_data(
    channel=True,
    filter_outputs=True,
    ground_truth=True,
    imu=True,
    snr=True
)

# 2. Start collecting
api.enable_collection()

# ... simulation runs for N steps ...
# (SimulationManager calls api.collect_sample() each step)

# 3. Check statistics
stats = api.get_statistics()
print(f"Collected {stats['sample_count']} samples")
print(f"Mean error: {stats['mean_error']:.3f} m")
print(f"LOS: {stats['los_percentage']:.1f}%")

# 4. Export
api.export_to_file("training_data.npz")       # NumPy compressed
api.export_to_file("training_data.csv", "csv") # Spreadsheet
api.export_for_pytorch("./pytorch_data/")      # PyTorch-ready

# 5. Convert to pandas
import pandas as pd
df = pd.DataFrame(api.get_synchronized_data())
print(df.describe())

AIGymServer

Bidirectional TCP server acting as a Gymnasium environment backend. Sends observations to an external RL client and receives actions.

from src.api.ai_gym_server import AIGymServer

server = AIGymServer(port=5555)
server.start()

Constructor

ParameterTypeDefaultDescription
portint5555TCP port to listen on

The server binds to 0.0.0.0 (all interfaces) so remote agents can connect.

Properties

PropertyTypeDescription
connectedboolWhether a client is currently connected
protocol_versionintCurrent protocol version (currently 2)

Methods

MethodParametersReturnsDescription
start()—NoneStart TCP server in a background thread
stop()—NoneStop server and close all connections
send_state(state_data)state_data: dict | list[dict]boolSend observation to client. Automatically injects protocol_version.
wait_for_action(timeout=None)timeout: float | Nonetuple[action, metrics] | NoneBlock until the client responds with an action. Returns None on timeout or disconnect.

PulseRLEnv (External Client)

Standard Gymnasium environment wrapper that connects to the PULSE Simulator. Install from the external_ai_client/ package.

# Install the package
cd external_ai_client
pip install -e .

# Use in your code
from pulse_ai_client import PulseRLEnv

Constructor

ParameterTypeDefaultDescription
portint5555TCP port to connect to
num_anchorsint8Number of anchors (defines action/observation space dimensions)

Spaces

SpaceTypeShapeDescription
ObservationBox(-100, 100)(num_anchors * 2 + 1,)Flattened anchor positions [x₁, y₁, x₂, y₂, ...] + localization error
ActionMultiBinary(num_anchors,)Binary mask: 1 = use this anchor, 0 = drop it

Enriched State (via info["full_state"])

Each step() call returns an info dict containing full_state with comprehensive data:

FieldTypeDescription
tag_position_gt[x, y, z]Ground truth tag position
tag_position_estimated[x, y]Estimated position from localization
measurements.uwb_rangesfloat[]UWB distance measurements per anchor
measurements.true_distancesfloat[]True distances per anchor
measurements.sourcestr"uwb", "imu", or "both"
imu_data.acceleration[ax, ay, az]Accelerometer readings (m/s²)
imu_data.angular_velocity[gx, gy, gz]Gyroscope readings (rad/s)
nlos_info.is_losbool[]LOS/NLOS per anchor
nlos_info.nlos_countintNumber of NLOS anchors
precision.localization_errorfloatCurrent error (meters)
precision.gdopfloatGeometric Dilution of Precision
energy.step_energy_uJfloatEnergy consumed this step (µJ)
energy.battery_life_hoursfloatEstimated battery life
energy.ranging_modestr"SS-TWR" or "DS-TWR"
environment.dtfloatSimulation time step (seconds)

Usage Example

from pulse_ai_client import PulseRLEnv

env = PulseRLEnv(port=5555, num_anchors=8)
obs, info = env.reset()

for step in range(1000):
    action = env.action_space.sample()  # Replace with your RL model
    obs, reward, terminated, truncated, info = env.step(action)

    # Access enriched state
    state = info["full_state"]
    print(f"Error: {state.error:.3f}m")
    print(f"NLOS anchors: {state.nlos_info.nlos_count}")
    print(f"Energy: {state.energy.step_energy_uJ:.1f} µJ")

env.close()

PulseClient (Low-Level)

Raw TCP client for custom integrations when the Gymnasium wrapper is not needed.

from pulse_ai_client import PulseClient

with PulseClient(port=5555) as client:
    states = client.receive_state()
    for state in states:
        print(f"Agent {state.agent_id}: pos={state.tag_position_gt}")
    client.send_action([[0, 1, 3]])  # Use anchors 0, 1, 3

TCP Protocol Specification

For building RL clients in any language (JavaScript, C++, Rust, etc.), you can communicate directly with the AIGymServer over TCP using newline-delimited JSON.

Connection

  • Host: localhost (or the simulator's IP for remote connections)
  • Port: 5555 (default, configurable in the GUI)
  • Protocol: TCP, newline-delimited JSON (\n as message separator)

Server → Client (State Message)

The simulator sends one JSON object per line. Each object contains:

{
  "protocol_version": 2,
  "agent_id": 0,
  "step": 42,
  "timestamp": 0.21,

  "tag_position_gt": [1.5, 2.3, 0.0],
  "tag_position_estimated": [1.48, 2.35],
  "localization_error": 0.058,

  "anchor_positions": [[0,0], [10,0], [10,10], [0,10]],
  "anchor_ids": [0, 1, 2, 3],

  "measurements": {
    "source": "uwb",
    "uwb_ranges": [3.21, 5.67, 2.89, 4.12],
    "true_distances": [3.18, 5.60, 2.85, 4.08]
  },

  "imu_data": {
    "acceleration": [0.02, -0.01, 9.81],
    "angular_velocity": [0.0, 0.0, 0.05],
    "enabled": true
  },

  "nlos_info": {
    "is_los": [true, false, true, true],
    "nlos_count": 1,
    "nlos_anchor_ids": [1]
  },

  "algorithm": {
    "name": "Extended Kalman Filter",
    "available_algorithms": ["EKF", "UKF", "Trilateration"],
    "filter_params": {}
  },

  "precision": {
    "localization_error": 0.058,
    "gdop": 2.4,
    "measurement_noise_stds": [0.05, 0.12, 0.04, 0.06]
  },

  "energy": {
    "total_power_mW": 12.5,
    "step_energy_uJ": 62.5,
    "battery_life_hours": 1200.5,
    "ranging_mode": "SS-TWR"
  },

  "environment": {
    "dt": 0.005,
    "movement_speed": 1.5,
    "movement_pattern": "circular",
    "measurement_source": "uwb"
  }
}

Client → Server (Action Message)

Your agent sends a JSON object per line:

// Protocol v2 — send selected anchor indices
{"action": [0, 1, 3]}

// Protocol v1 (legacy) — send binary mask
{"anchor_mask": [1, 1, 0, 1]}

JavaScript Client Example

const net = require('net');

const client = new net.Socket();
client.connect(5555, 'localhost', () => {
    console.log('Connected to PULSE Simulator');
});

let buffer = '';
client.on('data', (data) => {
    buffer += data.toString();
    const lines = buffer.split('\n');
    buffer = lines.pop(); // Keep incomplete line
    
    for (const line of lines) {
        if (!line.trim()) continue;
        const state = JSON.parse(line);
        console.log(`Step ${state.step}: error=${state.localization_error}m`);
        
        // Send action: use all anchors
        const action = { action: [0, 1, 2, 3] };
        client.write(JSON.stringify(action) + '\n');
    }
});
