Overview & Architecture

PULSE provides a dedicated AI training environment with a clear separation between the main simulation and AI training logic. This design allows researchers to train AI agents without interfering with the simulation engine.

Two training modes are supported:

🔄

Online Training (RL)

Real-time interaction between the simulator and an external RL agent over TCP. The agent receives observations, makes decisions (anchor selection), and the simulator applies them immediately. Supports Gymnasium (OpenAI Gym) interface.

💾

Offline Training (Data)

Batch data collection mode. The simulator runs scenarios while collecting UWB channels, CIR data, filter outputs, and ground truth into a buffer. Export as NPZ, CSV, JSON, or PyTorch datasets for supervised learning.

Scope Isolation

The AITrainingAPI creates a training-local copy of configuration. All SET operations (changing anchors, filters, energy profiles) modify only the training copy — the main simulation state is never affected. This means you can safely train agents while the main simulation runs independently.

Reinforcement Learning Training

The Problem: Smart Anchor Selection

In a UWB localization system with N anchors, some anchors may be in Non-Line-of-Sight (NLOS) conditions at any given moment. Using NLOS anchors introduces significant positive range bias, degrading localization accuracy.

The RL task is: learn to select the optimal subset of anchors to minimize localization error while maintaining robust geometry (GDOP).

How It Works

1. Server Side (Inside PULSE)

The simulator runs a built-in algorithm called "AI Gym Server (Port 5555)". When selected in the GUI, it starts the AIGymServer TCP server and waits for an agent to connect. At each simulation step, it:

  1. Computes the full simulation state (positions, measurements, NLOS, energy)
  2. Builds an enriched observation via build_step_observation()
  3. Sends the observation to the agent over TCP
  4. Waits for the agent's action (anchor selection)
  5. Applies the action and advances to the next step

2. Client Side (External Agent)

The external_ai_client/ package provides a standard gymnasium.Env wrapper (PulseRLEnv) that connects to the simulator via TCP. The agent:

  1. Receives observation (anchor positions + error)
  2. Runs its policy (neural network forward pass)
  3. Outputs an action (binary mask of which anchors to use)
  4. Receives reward based on localization improvement

Pipeline Stages Explained

  1. Initialization — User starts AI training from the GUI. The AIGymServer begins listening on TCP port 5555. The external agent connects.
  2. State Construction — At each step, build_step_observation() collects 15+ fields from the simulation into a single JSON-serializable dictionary.
  3. Communication — State is sent as a newline-delimited JSON message. The agent responds with its action (selected anchor indices) in the same format.
  4. Action Application — The simulator runs the localization algorithm (e.g., EKF) using only the anchors selected by the agent.
  5. Reward Computation — The agent computes its own reward based on the change in localization error (see below).
  6. Loop — The process repeats for each simulation time step (default dt = 5ms).

Observation & Action Spaces

Observation Space

The observation sent to the agent at each step contains:

CategoryFieldsDescription
Positions tag_position_gt, tag_position_estimated, anchor_positions Ground truth, estimated, and anchor positions
Measurements measurements.uwb_ranges, measurements.true_distances Noisy UWB measurements and true distances per anchor
IMU imu_data.acceleration, imu_data.angular_velocity 3-axis accelerometer and gyroscope readings
NLOS Info nlos_info.is_los, nlos_info.nlos_count Per-anchor LOS/NLOS status and total count
Precision precision.localization_error, precision.gdop Current error in meters, geometric dilution of precision
Energy energy.step_energy_uJ, energy.battery_life_hours Power consumption data for energy-aware policies
Environment environment.dt, environment.movement_speed Simulation configuration parameters

Action Space

The action is a binary mask or list of anchor indices indicating which anchors the agent wants to use for localization:

# Binary mask: [1, 0, 1, 1] → use anchors 0, 2, 3
action = env.action_space.sample()  # MultiBinary(num_anchors)

# Or as indices: [0, 2, 3]
{"action": [0, 2, 3]}

Complete Example

from src.api import TrainingDataAPI

# 1. Configure collection
api = TrainingDataAPI(buffer_size=50000)
api.select_data(
    channel=True,        # CIR and multipath data
    filter_outputs=True, # EKF/UKF state estimates
    ground_truth=True,   # True positions
    imu=True,           # Accelerometer + gyroscope
    snr=True            # Signal quality
)

# 2. Enable collection
api.enable_collection()

# 3. Run simulation... (data is automatically collected)

# 4. Check statistics
stats = api.get_statistics()
print(f"Collected: {stats['sample_count']} samples")
print(f"Mean error: {stats['mean_error']:.3f} m")
print(f"LOS ratio: {stats['los_percentage']:.1f}%")

# 5. Export in multiple formats
api.export_to_file("data.npz")                # NumPy compressed
api.export_to_file("data.csv", format="csv")   # Spreadsheet
api.export_for_pytorch("./pytorch_data/")      # PyTorch-ready

# 6. Direct pandas integration
import pandas as pd
df = pd.DataFrame(api.get_synchronized_data())
print(df.describe())

Setup & Training Guide

Prerequisites

# Install the external AI client package
cd external_ai_client
pip install -e .

# Install RL dependencies
pip install gymnasium numpy torch stable-baselines3

Step-by-Step Training

  1. Open PULSE Simulator GUI
  2. Click 🤖 Start AI to open the AI Training Window
  3. Set the Port (default: 5555) and Measurement Source (UWB / IMU / Both)
  4. Click ▶ Start Training — the simulator begins stepping and waits for your agent
  5. In a terminal, run your training script: 
    python train_agent.py
  6. Watch the GUI update in real-time as the agent learns

Port Configuration

The port must match on both sides:

  • GUI: Use the Port spinner in the AI Training Window toolbar
  • Code: Pass port=XXXX to PulseRLEnv(port=5555) or PulseClient(port=5555)
