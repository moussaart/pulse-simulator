Quick Start

Get a simulation running in under 5 minutes — from installation to your first results.

1. Install & Launch

🖥️ Windows

Option A: Installer (Fastest)

Download and run the Windows installer — no Python required.

Download Installer
🐍 Python

Option B: From Source

git clone https://github.com/moussaart/pulse-simulator.git
cd pulse-simulator
pip install -r requirements.txt
python main.py

2. Your First Simulation (2 minutes)

When the application opens, you'll see the main dashboard with a default scenario already loaded.

Step 1: Check the Default Scene

You should see 4 anchors (blue triangles) placed at the corners of the room and a tag (moving circle) with a predefined trajectory.

Step 2: Choose an Algorithm

In the Localization Algorithm panel on the right sidebar, select one of the built-in algorithms:

  • Trilateration — Simple geometric solution (fastest, no filtering)
  • Extended Kalman Filter (EKF) — Recommended for most scenarios
  • NLOS-Aware AEKF — Best accuracy in environments with obstacles

Step 3: Press ▶ Start

Click the Play button in the toolbar. The tag will start moving along its trajectory. Watch:

  • The green trail (estimated position) vs the blue trail (ground truth)
  • Signal rays changing from green (LOS) to red (NLOS) as the tag moves behind obstacles

Step 4: Open Analysis Windows

Go to View menu and open:

  • CIR Plot — Watch the Channel Impulse Response update in real-time
  • Distance Plot — Compare measured vs. true distances for each anchor
  • Error Metrics — Track RMSE and CDF plots

3. Add Obstacles (NLOS Testing)

To see how algorithms handle Non-Line-of-Sight conditions:

  1. Open the NLOS Obstacles panel
  2. Click "Draw Polygon"
  3. Click on the map to draw a wall between the tag path and an anchor
  4. Right-click to close the polygon
  5. Press ▶ Start again and observe the increased error when the tag passes behind the wall

Tip: Material Properties

Right-click any obstacle to change its material (Concrete, Glass, Wood). Each material has different signal attenuation properties, creating realistic NLOS conditions.

4. Quick Start: AI Training

Train an RL agent to intelligently select anchors in 3 steps:

Step 1: Start the AI Server

In the PULSE GUI, click 🤖 Start AI. This opens the AI Training window. Set the port (default: 5555) and click ▶ Start Training.

Step 2: Install the Client Package

cd external_ai_client
pip install -e .
pip install gymnasium numpy

Step 3: Run the Training Agent

python train_agent.py

The agent will connect to the simulator and start training. Watch the GUI update as the agent learns to select the best anchors.

Minimal Custom RL Agent

from pulse_ai_client import PulseRLEnv

# Connect to running PULSE simulator
env = PulseRLEnv(port=5555, num_anchors=8)
obs, info = env.reset()

for step in range(1000):
    # Your RL policy here (replace with trained model)
    action = env.action_space.sample()
    obs, reward, done, truncated, info = env.step(action)

    # Access full state
    state = info["full_state"]
    print(f"Step {step}: error={state.error:.3f}m, "
          f"NLOS={state.nlos_info.nlos_count}")

env.close()
